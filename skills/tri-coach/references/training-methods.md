# Training Methods — Swim, Bike, Run

Olympic distance: 1.5 km swim, 40 km bike, 10 km run. Race 14 November 2026.

Read `strength.md` for the gym. Read this for the three endurance sports.

---

## Evidence tiers — label everything you prescribe

- **Tier A — proven.** Consistent support in trained athletes. Prescribe by default.
- **Tier B — promising.** Plausible mechanism, emerging or mixed evidence. Use
  deliberately and say it is Tier B.
- **Tier C — unsupported.** Do not prescribe. If asked, explain honestly why not.

When the athlete's own logged response contradicts the population evidence, his
data wins. That is what the decision log is for.

---

## 1. The limiter, and what follows from it

**The run is the limiter.** Everything in this section follows from that.

Current state: longest run 6.3 km, paces 8:20–11:00 /km, mostly run-walk, heart
rate well below threshold. **The constraint is tissue tolerance and knee
capacity, not aerobic fitness.** His heart can already do this. His leg cannot
yet.

Three consequences:

1. **Run volume progresses on knee response, never on a schedule.** Green knee →
   add. Amber → hold. This overrides any plan on paper.
2. **Do not add run intensity to fix a run-distance problem.** Distance first.
   Speed is not the gap — 10 km at 9:30 /km finishes the race.
3. **The bike and the gym carry the aerobic load** while the run builds slowly.
   This is the correct use of a multi-sport race. Use it.

## 2. Run — building 6.3 km to 10 km in 8 weeks

### The method: run-walk, then bridge

He is already using run-walk. Keep it. It is Tier A for return-to-run and it is
exactly right for a knee that cannot yet take continuous load.

Progress in this order, one change at a time:
1. **Lengthen the run interval** (90 s → 2 min → 3 min → 5 min)
2. **Shorten the walk** (2 min → 1 min → 45 s)
3. **Only then add total distance**

Never change two of these in the same week.

### Weekly run structure — three runs

| Run | Purpose | Rule |
|---|---|---|
| **Long run (Sunday)** | The whole point of the block. | Grow about 10% per week from a green knee. Back off every 3rd or 4th week. This is the last session to ever be cut. |
| **Steady run (Wednesday)** | Aerobic quality. | Keep heart rate below 153 (Z2/low Z3). Not a hard session while the knee is the limiter. |
| **Easy run (Friday)** | Frequency without cost. | Genuinely easy. Short. If the week is going badly, this one goes first. |

### The target, stated honestly

From 6.3 km, a 10% weekly build reaches roughly 12 km by race week. That is
enough. Expect a race run leg around **9:30–10:30 /km**, so 95–105 minutes,
possibly with walk breaks through aid stations. That is a finish, not a fast
race, and it is the correct goal for this block.

**Say this to him plainly.** Do not let him arrive at race day expecting
something the data never supported.

### Missing: a run threshold pace

intervals.icu has no run threshold set. Do not field-test at maximum effort with
this knee. Instead, derive it from a controlled sub-maximal effort, or work from
heart rate until the knee tolerates a real test. Record whatever you set in
`athlete/metrics/` with the conditions and the date.

## 3. Bike — the strongest leg, so use it

FTP 250 W. Already covering 54.8 km at easy heart rate. **40 km is not in doubt.**

The bike's job in this block is to carry aerobic fitness that the run cannot yet
build. Two sessions per week.

| Session | Structure |
|---|---|
| **Intervals (Monday)** | 2–4 × 8–12 min at 88–100% FTP, equal-ish recovery. Or 4–8 × 3–5 min at 105–120% FTP for top-end. Both Tier A. |
| **Endurance (Saturday)** | Steady aerobic, 90–150 min. Build toward race distance and beyond. |

**Race pacing (Tier A):** Olympic distance is ridden hard — roughly 0.88–0.92 of
FTP for about 70–80 minutes. Practise it. From about mid-October, put 2 × 15 min
at race effort inside the Saturday ride.

**Brick sessions.** From week 3, finish one ride per week with a 10–15 min run
off the bike. This is the single most race-specific session available and it is
Tier A for triathlon. Keep the run short — it is about the transition feeling,
not about volume. The first kilometre off the bike always feels wrong; the point
is to make that familiar rather than alarming.

## 4. Swim — the gap is distance, not speed

Threshold pace 2:00 /100 m. That puts 1.5 km at roughly 30 minutes, which is a
fine Olympic-distance swim. Longest logged swim is 1.12 km.

**So the job is continuous distance, not speed.**

Three swims per week:

| Session | Purpose |
|---|---|
| **Tuesday lesson** (07:00) | Coach-led technique. Do not interfere. Ask what the coach is working on and support it. |
| **Thursday lesson** (07:00) | Same. |
| **Weekend solo** | This is the one you programme. Continuous-distance building. |

Solo session progression: build the longest continuous swim by about 100–200 m
per week. Reach 1.5 km continuous by mid-October, then repeat it until it is
routine. Add a broken race-pace set (for example 3 × 500 m) in the last month.

**Open-water items — resolve early:**
- Is the race swim in open water? Is a wetsuit allowed or is the water too warm?
  In the Gulf in November, a non-wetsuit swim is likely. **(ask)**
- If open water: practise sighting, a controlled first 200 m, and starting in a
  group. A pool-only swimmer in an open-water start is the most common way an
  Olympic-distance race goes wrong in the first five minutes.

## 5. Intensity distribution

Roughly 80% of sessions easy, 20% hard, is a solid Tier A default — but count
honestly. Easy sessions that drift into moderate are the most common mistake in
age-group training: easy days too hard, hard days too easy.

For this athlete the distribution is skewed further toward easy, because the run
cannot take intensity yet. The hard work lives on the bike and in the gym.

Short-course racing does want threshold and top-end work closer to the race. Add
it on the **bike** from mid-October. Add it to the run only if the knee is
consistently green and the long run is on track.

## 6. Block structure — 8 weeks

| Weeks | Dates | Focus |
|---|---|---|
| **1–2** | 21 Sep – 4 Oct | Build the habit. Run-walk intervals lengthen. Gym tolerance phase. Fix sleep. |
| **3–4** | 5 – 18 Oct | Load. Long run grows. First bricks. Swim reaches 1.5 km continuous. Gym loads up. |
| **5–6** | 19 Oct – 1 Nov | Race specificity. Bike race-effort sets. Brick runs lengthen. Peak gym. |
| **7** | 2 – 8 Nov | Taper begins. Volume down ~40%, intensity stays. Last heavy gym ≈ 4 Nov. |
| **8** | 9 – 14 Nov | Race week. See `race-execution.md`. |

Put a recovery week inside weeks 1–6 wherever the data says it is needed. With
form never yet positive and HRV falling, expect to need one sooner rather than
later. Do not wait for the plan to allow it.

## 7. Testing

Retest only when it changes a decision. Record every result in
`athlete/metrics/` with the date and conditions.

- **Bike:** confirm FTP 250 W is current. A ramp test or 20-minute test is fine —
  the knee tolerates cycling well. **(ask)** when it was last tested.
- **Swim:** one continuous 1.5 km time trial in early October. This is the single
  most useful swim number and it removes the biggest unknown.
- **Run:** no maximal test. Use a controlled effort and heart rate instead.
- **Strength:** progression is read from Hevy, not tested separately.
